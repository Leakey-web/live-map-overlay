# 車掃直播 GPS 小地圖

全靜態網頁，部署在 GitHub Pages。手機用 RealtimeIRL 回傳定位，OBS 疊上圓形即時地圖。

底圖使用內政部國土測繪中心的「臺灣通用電子地圖」開放資料，**不需要地圖金鑰，也不用綁信用卡**。

| 檔案 | 用途 |
| --- | --- |
| `overlay.html` | OBS 瀏覽器來源，透明背景，1920x1080 |
| `admin.html` | 小地圖設定頁，用來產生 OBS 網址與複製標示文字 |
| `config.js` | 頭像、位置、顏色與圖資標示 |
| `avatar.png` | Q 版頭像，請自行放入。沒有檔案時會顯示藍色定位點 |

---

## 一、換一台電腦怎麼用

網站放在 GitHub Pages，**不需要開著原本的電腦，也不用安裝任何東西**。

1. 用任何電腦開啟設定頁：`https://leakey-web.github.io/live-map-overlay/admin.html`
2. 貼上 RealtimeIRL Pull Key，填入延遲秒數，按「產生 OBS 網址」。
3. 按「開啟測試畫面」，確認 GPS 和地圖狀態正常。
4. 複製 OBS 網址，貼到該電腦 OBS 的瀏覽器來源（第三節）。
5. 複製「直播說明欄必貼文字」，貼到這場直播的說明欄。

已經產生過的 OBS 網址也可以直接私下傳給導播，貼進 OBS 就能用。

> **OBS 網址等於定位鑰匙。** 裡面含有 Pull Key，請用私訊傳遞，不要貼到公開群組或直播留言。

### 分享給其他團隊

- **同一個團隊**：直接使用上面的網址即可。
- **其他團隊**：請對方 Fork 這個專案，並使用自己的 RealtimeIRL 帳號。

### 沒有 Pull Key 也能先看效果

開啟 `overlay.html?demo=1` 會用模擬 GPS 在高雄市區移動地圖。

## 二、車上設定 RealtimeIRL

1. 在隨車手機安裝 **RealtimeIRL**（App Store / Google Play），並到 [rtirl.com](https://rtirl.com) 建立帳號。
2. 在 App 或帳號頁找到 **Pull Key**。
3. 定位權限設為「**永遠允許**」，並開啟「精確位置」。
4. 關閉這支手機的省電模式。Android 請把 RealtimeIRL 設為「不限制電池用量」。
5. 接上行動電源，手機放在看得到天空的位置，例如擋風玻璃旁。
6. 開播前按下開始回傳，收播後**一定要關閉**，避免持續回傳位置。
7. 檢查 RealtimeIRL 的隱私設定，確認位置沒有公開顯示在 rtirl.com 上。

建議用一支**專用手機**回傳定位，不要和直播背包共用。

## 三、OBS 設定

新增「瀏覽器」來源：

| 設定 | 值 |
| --- | --- |
| URL | `admin.html` 產生的 OBS 網址 |
| 寬度 / 高度 | `1920` / `1080` |
| 自訂影格率 | 開啟，`30` |
| 來源不顯示時關閉 | **不要勾** |
| 場景啟用時重新整理瀏覽器 | **不要勾** |

把這個來源放在場景最上層，位置 `0,0`，不要縮放。

### 對齊 4G 背包畫面延遲

**請用 OBS 網址裡的 `delay=`，不要靠「算圖延遲（Render Delay）」。** Render Delay 單一濾鏡上限通常只有 500 毫秒，而 4G 背包常見延遲是好幾秒；疊多個濾鏡也會吃顯示卡記憶體。

校正方式：

1. 開播前讓車子實際行駛，找一個明顯的路口。
2. 比對**畫面中車子過路口**和**地圖頭像過路口**的時間差。
3. 地圖比畫面早，就把 `delay` 調大；地圖比畫面晚，就調小。單位是毫秒：

```text
...overlay.html#pull=你的Key&delay=3500
```

4. 改完網址後按來源的「重新整理」。

### 除錯

在網址的 `#` 前加上 `?debug=1`，畫面左上角會顯示 GPS 與地圖狀態。**正式開播前請移除。**

```text
...overlay.html?debug=1#pull=你的Key&delay=3500
```

## 四、圖資授權與標示

地圖依「政府資料開放授權條款－第 1 版」使用，可免費用於直播，但**一定要標示來源，否則視為未取得授權**。

- 每場直播都到 `admin.html` 複製「直播說明欄必貼文字」，貼到直播說明欄。
- 不要裁切或遮掉地圖上的 NLSC 浮水印。
- 浮水印日期改變時，請更新 `config.js` 裡 `mapCredit` 的版本。
- 條款沒有規定標示要放在哪裡。放在說明欄是合理做法，若要完全確定，可洽國土測繪中心。

開放圖資最大縮放層級是 `15`，超過只會得到空白圖磚，所以程式已限制上限。

## 五、調整位置與顏色

都在 `config.js`：

- **位置**：`map.right`、`map.bottom`。預設放在 QR Code 正上方；若要貼齊右下角，把 `bottom` 改成 `40`，但會蓋住 QR Code。
- **縮放**：`map.zoom`，可用 `14` 或 `15`。
- **顏色**：`theme.ring`，預設為藍色。

更新 `config.js` 或放入 `avatar.png` 時，把檔案上傳到 GitHub 專案的 `main` 分支，約一分鐘後生效，再到 OBS 按來源的「重新整理」。

## 六、緊急備援

如果政府圖資服務中斷，可以換成 RealtimeIRL 官方圖層。它沒有圓框、頭像和延遲對齊，地圖上也會有 Mapbox 標示，但能立刻頂上：

```text
https://overlays.rtirl.com/generic.html?key=你的PullKey&zoom=15
```

請在開播前測試一次，並把它先放在 OBS 的隱藏來源裡。

## 七、開播前檢查

- [ ] 手機 GPS 已開始回傳，電源接好，省電模式關閉
- [ ] OBS 地圖有出現，頭像在圓心，路名清楚
- [ ] 地圖沒有蓋到 QR Code 與主視覺
- [ ] 實際行駛校正過 `delay`
- [ ] 直播說明欄已貼上圖資標示文字
- [ ] OBS 網址沒有 `?debug=1` 或 `?demo=1`
- [ ] 備援圖層已放在隱藏來源
- [ ] 收播後關閉 RealtimeIRL 回傳

### 常見問題

| 狀況 | 處理方式 |
| --- | --- |
| 地圖完全沒出現 | 加 `?debug=1` 看狀態。圖層在收到 GPS 並載入圖資前會保持隱藏 |
| 地圖部分空白 | 通常是網路或圖資服務暫時不穩，程式會自動重試。持續發生就切換備援圖層 |
| 地圖停住不動 | 通常是手機斷線或被系統休眠。地圖會停在最後位置，恢復後自動續跑 |
| 地圖比畫面早或晚 | 調整 OBS 網址的 `delay=` |
